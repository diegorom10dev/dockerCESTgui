# INSTALLATION

### 1.1 Install Docker Desktop

Install Docker's desktop application by visiting the official documentation:

[https://docs.docker.com/desktop/](https://docs.docker.com/desktop/)

### 1.2 Download the Docker Image

Download the project's Docker image (`cest_ui_prod_v1.0.tar`) to a **directory with writing permissions**.

### 1.3 Download the Installation Script

Download the installation script (`install.cmd`) in the **same directory used in step 1.2**.

### 1.4 Run the Installation Script

Execute the installation script by double-clicking on the file (`install.cmd`).

After the installation process is completed, your default web browser (Google Chrome, MS Edge, Firefox, etc.) should automatically open with a tab pointing to `127.0.0.1`.
