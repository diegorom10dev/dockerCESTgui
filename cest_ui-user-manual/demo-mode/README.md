# DEMO MODE OVERVIEW

Demo Mode allows you to explore the application's features using pre-loaded patient data, without requiring your own files. It is the recommended starting point for new users.

Two sub-modes are available:

* [2.1 Single Patient Mode](single-patient) — Process and classify one lesion at a time for a selected demo patient.
* [2.2 Batch Mode](batch-mode) — Run automated inferences across multiple demo patients and lesions simultaneously.
